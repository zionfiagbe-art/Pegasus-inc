# HAMBURG NIGHT RUN

2D-Sidescroller-Browserspiel (HTML5, CSS3, Vanilla JavaScript). Neon-Noir-Optik, Hamburg bei Nacht, neun Kapitel mit Kämpfen, Bossen und Story-Szenen.

## Inhalt

| Datei | Was drin ist |
|---|---|
| `index.html` | Das spielbare Spiel (alle Kapitel, Steuerung, Sound) |
| `menu.html` | Titelmenü / Cover-Motiv als eigene Seite |
| `story/dialoge.md` | Dialogszenario Kapitel 1–8 |
| `story/storybibel.md` | Figuren, Welt, Regeln der Story |
| `reference/menu-ausgangsbasis.html` | Ursprüngliches Menü-Grundgerüst (Referenz) |

## Starten

`index.html` im Browser öffnen. Kein Server, kein Build-Schritt nötig.

## Steuerung

- Laufen: A / D oder Pfeiltasten
- Springen: W / Leertaste
- Schläge, Tritte, schwere Attacke, Spezial, Dash: J / K / L / U / I
- Pause: P oder Esc
- Auf dem Handy: Bildschirm-Tasten

## Figuren

- **MIRA** – schnell, Tritte, Dash
- **KAI** – stark, Konter, Griffe
